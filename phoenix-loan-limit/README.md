# 微型創業鳳凰貸款申請書產生器（課程教學版）

一個單檔、免安裝的網頁工具，協助微型創業者（或輔導顧問）撰寫勞動部勞動力發展署「微型創業鳳凰貸款」申請書。用瀏覽器打開 `index.html` 即可使用，不需要架伺服器、不需要安裝任何軟體。

> ⚠️ **使用警語**
> 本工具僅供教學、課程及個人使用，**禁止未經授權公開發布、販售或商業化使用**。
> 本工具為填表輔助性質，並非官方申請系統；產出內容仍需謄寫或對照填入勞動部官方申請書表，實際申請條件與核貸結果以勞動部勞動力發展署及承貸金融機構之審查為準。

**課程教學版與一般版的差異**：功能完全相同，但畫面最上方 banner 有一個**課程授權序號**欄位，自全班第一次使用序號起提供 **4 個月**使用期限，banner 上會顯示剩餘可用天數；逾期後 AI 優化功能停用，其餘功能（計畫書整合、列印匯出、上傳辨識、離線規則式生成／優化）不受影響、可長期使用。AI 優化**不需要自己申請 API 金鑰**——留空即使用課程內建的 AI 服務。網站標題列採**紅色 banner** 以與其他版本區隔。

## 功能總覽

### 1. 分頁填表
依官方申請書架構分為五個分頁：

| 分頁 | 對應官方書表 |
|---|---|
| 一、申請人基本資料 | 壹、申請人基本資料（含經歷、職訓、聯絡親友） |
| 二、所營事業資料 | 貳、所營事業資料（登記、地址、營業項目） |
| 三、財務與資金計畫 | 財務分析、資金來源、借款情況、現有設備、資金用途明細 |
| 四、創業貸款計畫書 | 經營現況、市場分析、償貸計畫、自傳簡述 |
| 五、預覽與列印 | 整合後的完整申請書，可直接列印／匯出 PDF |

所有內容自動儲存在瀏覽器本機（localStorage），關掉頁面再打開資料仍在。

### 2. 內建 5 組虛構產業範例
早餐店、手工皮革工作室、寵物美容店、手作保養品電商、居家清潔服務——供教學示範使用。範例中的人名、統編、電話、地址皆為虛構。

### 3. 上傳申請書自動辨識（PDF／Word）
上傳既有的申請書 docx 或 PDF，工具會以規則式比對自動擷取欄位（姓名、統編、勾選項目、各節段落等）並填入表單，附辨識結果報告。**檔案全程在你的瀏覽器本機解析，不會上傳到任何伺服器。**
（掃描影像檔的 PDF 沒有文字層，無法辨識，請改用 Word 檔。）

### 4. 數字一致性檢查
「資金用途明細加總」與「尚需資金總額」即時核對，不相符會標紅提醒——這是申請書最常見的補件原因之一。

### 5. 一鍵生成／優化（離線規則式）
依你填的數字與事實，本機重算每月攤還本金／本息、重組貸款用途說明、生成獲利轉正說明（含償貸能力檢核）與自傳骨架。不會連網、不會捏造數字，缺少的事實以【】標示請你補填。生成前自動備份，可一鍵復原。**不受授權序號期限限制，永久可用。**

### 6. AI 優化（選用，需課程授權序號）
可串接 Claude（Anthropic）、OpenAI、Gemini（Google）、OpenRouter，讓語言模型參考目前內容重寫計畫書的敘述段落。

- **需先在畫面最上方 banner 輸入課程講師提供的「課程授權序號」**並按「驗證」，序號自全班第一次使用起提供 4 個月使用期限，banner 會顯示剩餘可用天數；逾期後即使換用免費的 AI 服務商／金鑰也無法使用本功能
- **API 金鑰可留空**：留空時使用課程內建的 AI 服務（由講師的金鑰負擔用量），一樣受序號期限限制；也可以自行填入自己的 API 金鑰（只儲存在這台電腦的瀏覽器，請勿在共用電腦上填寫）
- 按下優化時，會先連線確認序號是否在有效期間內，通過後計畫書內容才會傳送給所選的模型服務商（或課程內建服務）
- 數字欄位不交給 AI 改寫；AI 輸出仍需逐段核對後再使用
- 服務商暫時過載或限流（如 503、429）時會**自動重試最多 2 次**（間隔 8、16 秒）；重試後仍失敗，請稍候幾分鐘再按一次，或更換模型／服務商

**優化方向提示詞（選填）**：可以用一段話告訴 AI 你希望計畫書往哪個方向強化，AI 會優先遵循（但仍不得捏造事實）。內建三組範例可一鍵套用：

| 範例 | 適用情境 |
|---|---|
| ① 強化還款能力 | 財務數字普通、想讓審查人員放心「每月攤還沒問題」時 |
| ② 強化客源基礎 | 已有穩定熟客或在地口碑，想凸顯「生意做得起來」時 |
| ③ 強化資金效益 | 申貸用途以設備或週轉金為主，想說清楚「錢花在刀口上」時 |

## 使用方式

1. 直接用瀏覽器（建議 Chrome / Edge）開啟 `index.html`
2. 從範例下拉選單載入一組範例觀察格式，或按「清空重填」從頭開始
3. 依分頁順序填寫，於「預覽與列印」檢視整合結果
4. 按「列印／匯出 PDF」輸出，再對照謄寫至官方申請書表
5. 若要使用 AI 優化，先在畫面最上方 banner 輸入課程講師提供的授權序號並按「驗證」，確認顯示「剩餘 N 天可用」；API 金鑰留空即用課程內建服務，或自行填入自己的 API 金鑰

## 隱私說明

- 表單資料只存在你自己瀏覽器的 localStorage，不會傳送到任何伺服器
- 會連網的功能：授權序號驗證（確認序號有效並顯示剩餘天數）、AI 優化（若用課程內建服務，計畫書內容會經授權伺服器轉送給服務商；若自行填金鑰則直接傳給你選擇的服務商）、PDF 解析（從 CDN 載入 pdf.js 程式庫，但你的檔案內容不會上傳）
- 授權序號驗證本身只會傳送「序號」，不會傳送你填寫的任何申請書內容
- 處理真實申請人資料時，請務必於申請人自己的裝置上操作，並注意個資保護

## 給教師：授權伺服器設定

AI 優化功能的序號期限檢查，是透過部署在你的 Google Sheet 上的 Apps Script 完成的；這支 Apps Script 同時也是「課程內建 AI 服務」的代理（學員不用自己申請金鑰）。**首次啟用前需要手動部署一次**，步驟見同資料夾的 [`SETUP-授權伺服器設定.md`](./SETUP-授權伺服器設定.md)。部署完成後，開新班級只需要在 Google Sheet 新增一列序號即可，不需要重新部署。
