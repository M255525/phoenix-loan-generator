一鍵生成／優化計畫書內容

依目前已填的數字與事實，離線以規則模板重組內容（純本機運算，不會連網、不會上傳資料）。
會覆蓋：損益說明（空白或過短時）、貸款用途及效益說明、償貸每月攤還數字（依貸款金額／期間／利率重算）、獲利轉正說明、自傳簡述。其他敘述欄位不更動。生成前會自動備份，可一鍵復原。

AI 優化（串接語言模型 API）

讓語言模型參考目前已填的全部內容，重寫計畫書的敘述段落——數字與事實不會被更動，缺少的具體事實會以【】標示請你補填。
API 金鑰可留空：留空時會使用課程內建的 AI 服務（由講師的金鑰負擔用量），一樣受序號使用期限限制；若你想用自己的服務商帳號／額度，也可以自行填入 API 金鑰（只會存在這台電腦的瀏覽器，請勿在共用電腦上填寫）。
注意：按下優化時，目前的計畫書內容會傳送給所選的模型服務商（或課程內建服務）。優化前會自動備份，可用上方「復原生成前內容」還原。
本功能需在上方 banner 輸入課程講師提供的授權序號才能使用，序號自全班第一次使用起提供 4 個月使用期限，逾期後本功能將無法使用（計畫書整合列印功能不受影響）。

三、償貸計畫

如果「申貸前1年損益」是虧損，這裡務必說明清楚為什麼貸款到位後可以轉為預估淨利，並盡量附上具體假設（例如營業額提升幅度、毛利率變化），否則審查人員會質疑數字是否可信。

四、自傳簡述（含創業動機）

建議聚焦在：相關經驗年資、人脈與客源基礎、創業動機、還款能力／家庭因素。避免離題描述職場恩怨或情緒化用語，這些內容與貸款審核無關，反而可能讓人對經營穩定性產生疑慮。
